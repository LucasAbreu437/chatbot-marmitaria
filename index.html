Camadas de Proteção Ativas Nível Máximo
  • Filtro Léxico Anti-Jailbreak: Bloqueia comandos como "ignore as instruções", "system prompt", "DAN", "modo desenvolvedor" antes de chamar a API.
  • Blindagem de Preços Client-Side: O LLM nunca calcula preços livres. Ele apenas envia o ID do prato em JSON e o JavaScript aplica o preço oficial da tabela.
  • Validação de Cardápio do Dia: Impede adicionar pratos de outros dias da semana ou códigos inexistentes.
  • Sanitização XSS: Todo texto exibido no DOM é escapado contra injeção de HTML/Scripts.

Gerador de Links de Entrega da Atividade

Repositório: https://github.com/seu-usuario/chatbot-marmitaria-llm

Passo a Passo Rápido para Publicar no GitHub Pages:

  1. Crie um repositório público no GitHub chamado chatbot-marmitaria-llm.
  2. Salve o código desta aplicação em um arquivo único chamado index.html na raiz do repositório.
  3. No GitHub, acesse Settings → Pages.
  4. Em Build and deployment (Source), selecione Deploy from a branch e escolha a branch main (pasta /root) e clique em Save.
  5. Aguarde 1 minuto e acesse a URL gerada do seu GitHub Pages!
